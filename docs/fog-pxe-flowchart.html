PXE Boot Sequence

1
VirtualBox VM Powers On
Boot order: Network first (linux) / DVD→Disk (win10)
NIC sends PXE-enabled DHCP Discover broadcast
linux — 82545EM — Bridged eno1 win10 — Am79C973 — Bridged eno1
Broadcast UDP:68 → 255.255.255.255
2
OpenWrt Router — DHCP Offer
Assigns IP from pool · Sends PXE boot options
next-server = 10.0.0.10 · filename = undionly.kpxe
10.0.0.1 — LAN DHCP Range: .100–.250
DHCP ACK + boot options
3
TFTP Download — undionly.kpxe
VM contacts TFTP server at 10.0.0.10:69
Downloads undionly.kpxe (~363 KB) — iPXE chainloader
tftpd-hpa — 10.0.0.10:69 UDP /tftpboot/undionly.kpxe
TFTP RRQ — undionly.kpxe
4
iPXE Boots — Second DHCP (Proxy)
undionly.kpxe sends new DHCP with user-class: iPXE
dnsmasq on FOG server detects tag & responds on port 4011
dnsmasq Proxy — 10.0.0.10:4011 UDP tag:ipxe → boot.php
dhcp-boot: http://10.0.0.10/fog/service/ipxe/boot.php
5
Apache2 / FOG Web Server
HTTP GET /fog/service/ipxe/boot.php?mac=XX:XX:XX:XX:XX:XX
FOG looks up MAC in database · Returns iPXE menu script
10.0.0.10:80 — Apache2 FOG Project DB (MySQL)
HTTP 200 — iPXE menu script
6
FOG Boot Menu Displayed
VM shows interactive iPXE menu with options:
Boot from local disk Deploy Image Capture Image Run Memtest86+ Full Registration
User selects action
7
Action Executed
Capture: FOG agent boots, streams disk image to FOG server
Deploy: FOG streams image back to VM via multicast/unicast
Memtest: TFTP fetches memtest.bin, runs in RAM
Local disk: Chainloads to existing OS bootloader

dnsmasq — Proxy DHCP

/etc/dnsmasq.d/fog-proxydhcp.conf 
# Proxy-only — no IP assignment
log-dhcp
dhcp-range=10.0.0.0,proxy

# Tag second-stage iPXE clients
dhcp-userclass=set:ipxe,iPXE

# Tell pre-iPXE clients what to chainload
pxe-service=tag:!ipxe,x86PC,"Boot from FOG",undionly.kpxe,10.0.0.10
pxe-service=tag:!ipxe,X86-64_EFI,"Boot from FOG",ipxe.efi,10.0.0.10

# Listen on LAN NIC only
interface=eno1
except-interface=lo
except-interface=docker0

# Send FOG URL to full iPXE, fallback to TFTP
dhcp-boot=tag:ipxe,http://10.0.0.10/fog/service/ipxe/boot.php
dhcp-boot=tag:!ipxe,undionly.kpxe,,10.0.0.10

OpenWrt Router — DHCP Boot

/etc/config/dhcp (router) 
# UCI section cfg06b399
config boot
    option filename      'undionly.kpxe'
    option serveraddress '10.0.0.10'
    option servername    'fogserver'

# Applies to ALL clients (no networkid filter)
# Sends DHCP options 66+67 with FOG TFTP details

iPXE Boot Script

/tftpboot/fog.ipxe 
#!ipxe
echo Starting FOG Boot...
ifstat
set fog-ip       10.0.0.10
set fog-webroot  fog
chain --replace http://${fog-ip}/${fog-webroot}/service/ipxe/boot.php?mac=${net0/mac}

Fallback Chainloader

/tftpboot/default.ipxe

Known Issues & Fixes

"Nothing to boot"
next-server pointing to wrong host
Ensure router sends next-server=10.0.0.10
dnsmasq silent
dhcp-authoritative in proxy config
Remove dhcp-range IPs, dhcp-option, dhcp-authoritative
TFTP uppercase fail
ISO9660 without Joliet/RockRidge
Use genisoimage -J -R flags
networkid=bios filter
VirtualBox doesn't send client-arch
Remove networkid from boot UCI section
